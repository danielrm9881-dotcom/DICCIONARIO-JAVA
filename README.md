# Mini Diccionario Español - Inglés (Práctica de Lógica de Programación)

Este proyecto forma parte de los ejercicios prácticos de programación en Java. Consiste en una aplicación de consola que evalúa el vocabulario del usuario mediante un juego de traducción aleatoria.

## 🚀 ¿Qué hace el programa?

1. **Diccionario Interno:** Almacena un conjunto de más de 20 palabras en español con su respectiva traducción al inglés utilizando la estructura de datos `HashMap`.
2. **Selección Aleatoria:** Extrae de manera totalmente aleatoria **5 palabras** en español del diccionario general en cada ejecución.
3. **Evaluación Interactiva:** Le pide al usuario que teclee la traducción al inglés para cada una de las palabras seleccionadas y comprueba instantáneamente si la respuesta es correcta.
4. **Resultados Finales:** Muestra por consola un resumen detallado con el total de respuestas correctas e incorrectas obtenidas por el usuario.
